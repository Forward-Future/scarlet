# Reporting a security issue

Report a suspected vulnerability privately to the Scarlet maintainers through [GitHub private vulnerability reporting](https://github.com/Forward-Future/scarlet/security/advisories/new).

Include the affected Scarlet version, operating system, and what you observed. Use generated media or a sample project if an example helps explain the issue. Remove credentials, personal footage, transcripts, and file paths before attaching logs. The maintainers can follow up in the private report.
