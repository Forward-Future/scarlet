# Scarlet code of conduct

Everyone is welcome to contribute to Scarlet. In issues, pull requests and other project spaces, discuss the work respectfully. Give specific feedback, make room for questions and respect people’s privacy.

Harassment, threats, discriminatory abuse and sharing someone’s private information without permission are grounds for moderation. Maintainers may remove content, close a discussion or restrict participation.

If you see abuse, you can report the comment or account privately to GitHub through its reporting menu. Avoid quoting private information in a public issue. [How to report abuse on GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
