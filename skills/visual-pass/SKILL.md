# Visual pass

Add cutaways, supplied images, graphics or labels over an edit whose dialogue timing stays as it is. The brief and the surrounding footage decide the assets, placement, duration and sound.

`frame_contact_sheet` shows scene changes in a source or the composition on a version. `asset_add` imports supplied files. `timeline_propose` adds tracks and places, trims, layers, mutes or transforms clips.
